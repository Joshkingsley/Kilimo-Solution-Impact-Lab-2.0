Nitapata?
Will I get it — says which document, which page.

An SMS assistant for smallholders on the National Fertiliser Subsidy Programme. It answers eligibility, process and price — never what to plant — and every figure is traceable to a named public document and page. The farmer needs a feature phone and nothing else.

  • 1 · Cited answer — figure + [Document, Page, Date] from the corpus
  • 2 · One clarifying question — e.g. “which ward/depot?”, asked once
  • 3 · Stated boundary — “that’s not in the public documents” / out of scope
  • ✕ Never a fourth option. The system does not improvise.

Decide before a single line of build code

The two points to pin — Day 0

Pin № 1

Which demo county?

Machakos (matches the Nyambura persona) — if and only if its published documents can actually answer all three questions: does the depot serve me, what am I missing, what does the bag cost. If they can’t, we switch to the best-documented county (e.g. Kakamega, which has a published price announcement) and rewrite the persona to match.

How we decide: the Day-0 document hunt. Download the candidates, check the three answers exist on real pages. One county done properly beats eight done vaguely.

Pin № 2

What counts as a primary citation?

A Gazette notice pricing the current cycle may not exist — prices often land via Ministry of Agriculture and NCPB statements instead. We pin the citation hierarchy now: Ministry + NCPB documents are acceptable primary citations for figures; the Gazette notice anchors the programme’s legal basis.

How we decide: confirm during the Day-0 hunt which document types actually carry the current-cycle price, and write the hierarchy into corpus/sources.yaml so retrieval ranks them consistently.

Non-negotiable

Fixed rules

The four guardrails

  1. No agronomic advice. Eligibility and process — never what/when to plant, never what will happen to a crop.
  2. Not a marketplace. No buying, selling, payments, credit or insurance — not even steering towards one.
  3. A figure with no document behind it is a failed guardrail. Uncited number in a draft → the draft is discarded, fallback line sent.
  4. No farmer database. No accounts, no history. The only persistent store is the public-document corpus.

Rejected in ideation — do not resurrect

Satellite risk-of-loss scoring, yield / days-to-reap prediction, insurance, credit. Each one fails the citation test unconditionally — a model score has no gazette page behind it. Pitching them reads as not having internalised the constraint. They are a different product with a different risk classification, not a stretch goal of this one.

How it works

Architecture & flow

[ONLINE, PERIODIC — operator runs it] [PER MESSAGE — Worker] Gazette / NCPB / kilimo.go.ke / county PDFs Farmer SMS → Africa's Talking webhook │ nitapata ingest (Python CLI) │ ▼ 1 normalise (Kiswahili/Sheng/EN) parse (OCR fallback) → chunk (+page) → embed 2 scope gate ── out of scope → boundary line │ 3 split compound asks ▼ 4 resolve depot ── missing → 1 clarifying Q Cloudflare Vectorize + D1 5 retrieve (cycle + county filter) (the corpus is the ONLY database) 6 generate (Haiku, cite-or-refuse prompt) 7 citation check ── uncited figure → fallback Astro demo UI + judge panel ─────────────────► 8 GSM-7 segment → reply (≤2 SMS)

Stack

  • Ingestion: Python 3.12, pdfplumber + tesseract OCR, ruff, pytest
  • Answer service: TypeScript (strict) Cloudflare Worker
  • Storage: Vectorize (chunks), D1 (metadata), KV (15-min clarify state, hashed key)
  • Embeddings: Workers AI bge-m3 (multilingual)
  • LLM: Claude Haiku 4.5 — classification + generation
  • SMS: Africa’s Talking sandbox
  • Demo UI: Astro, static, judge citation panel

Privacy & honesty posture

  • No farmer PII at rest — clarify state is hashed-key, intent-only, expires ≤15 min
  • Logs strip phone numbers (grep-verified in review)
  • Comparison questions the corpus can’t support (“has the price gone up?”) get the current cited figure + an explicit decline — never an invented trend
  • If venue Wi-Fi dies: recorded replay of the eval transcript, clearly labelled “recorded run”

Build plan

Day 1

Ingestion end-to-end.Parse → chunk (+page) → embed → Vectorize. Retrieval sanity-checked against the three Nyambura questions. Embedding-model gate: if bge-m3 fumbles Kiswahili retrieval, swap to a hosted multilingual API today, not later.

Day 2

Worker pipeline + eval harness together.Scope gate, retrieval, generation, post-generation citation check, fallback lines, KV clarify flow. evals/messages.yaml: ≥30 cases (six intents + adversarial), each asserting an outcome class — cite / clarify / boundary.

Day 3

Channels.Africa’s Talking sandbox wiring; Astro demo UI + judge citation panel; GSM-7 segmentation within a 2-SMS budget.

Day 4 ·½

Red-team + review + pitch dry-run.Adversarial evals, recorded-replay demo mode, reviewer checklist, and a dry-run against the judges’ question: which document, which page?

Working together

Team collaboration — how to plug in

  1. Read SPEC.md first.It is the contract. The fixed rules and non-goals are not open for re-negotiation mid-build; if you think something must change, raise it before writing code.
  2. Clone and set up.git clone <repo> → Python: python -m venv .venv && pip install -r requirements.txt · Worker: npm install → npx wrangler dev. Secrets via wrangler secret / .dev.vars — never committed.
  3. Claim a lane.A — Corpus & ingestion (Python). B — Worker pipeline & guardrails (TypeScript). C — SMS + demo UI & judge panel. D — Evals & red-team. Lanes touch at two interfaces only: the chunk metadata schema and the Worker’s message contract — agree those on Day 0 and freeze them.
  4. Branch per task, small commits.Branch off main as feat/scope-gate, fix/gsm7-segmentation… Conventional prefixes: feat: fix: chore: docs: test:. main stays deployable at all times.
  5. Every PR ships with an eval case.New behaviour = new entry in evals/messages.yaml. The harness replaying green is our merge gate — no eval, no merge.
  6. Daily 10-minute sync.Three questions each: what merged, what’s blocked, does anything threaten a fixed rule. Anything threatening a guardrail stops the line immediately.
  7. Definition of done.Acceptance criteria in SPEC.md pass, eval harness green in CI, reviewer checklist run clean, committed and pushed. Not before.
